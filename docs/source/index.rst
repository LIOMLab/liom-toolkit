============
Liom Toolkit
============

This is the documentation of the LIOM Toolkit. The package supports the
research being done by the `Laboratoire d'Imagerie Optique et Moléculaire
<https://liom.ca/>`_ at Polytechnique Montréal. It hosts a collection of
scripts used to process and analyze data collected by the lab.
